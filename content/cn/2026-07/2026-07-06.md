# 数据安全与API安全日报 | 2026年7月6日

## 📜 政策合规

1️⃣ **公安部通报37款违规应用，电商类占比超七成**  
依据《网络安全法》《个人信息保护法》，公安部检测发现37款移动应用存在违法违规收集使用个人信息情况，涉及支付宝、微信小程序等生态。电商类应用占比超70%，未公开收集使用规则是主要违规项。监管部门明确表示“小程序不再是法外之地”。  
🔗 https://www.4hou.com/posts/PGXA

2️⃣ **小程序合规压力升级，支付宝/微信小程序成重灾区**  
此次通报中，《奇峰商城》《聚优商城》《亿秀分期商城》等21款应用因未公开收集使用规则上榜，覆盖支付宝、微信双平台。专家指出，小程序开发门槛低、审核宽松，后续监管将重点聚焦第三方平台主体责任落实。

## 🚨 漏洞威胁

1️⃣ **Adobe ColdFusion 最大严重漏洞已遭在野利用（CVE-2026-48282）**  
漏洞情报公司 KEVIntel 确认，攻击者正在利用 Adobe ColdFusion 的一个最高严重性漏洞（CVSS 评分 10.0）。该漏洞影响多个版本，可导致远程代码执行。Adobe 已发布安全更新，但大量服务器仍未修复，建议立即升级。  
🔗 https://www.bleepingcomputer.com/news/security/max-severity-adobe-coldfusion-flaw-now-exploited-in-attacks/

2️⃣ **Popa 僵尸网络关联以色列上市公司，数百万 Android TV 盒子被控制**  
过去四年间，名为 Popa 的 Android 僵尸网络通过恶意固件感染数百万电视盒子，被用于广告欺诈、账户接管和数据窃取。安全调查发现其运营者与一家以色列上市公司存在关联，目前多家执法机构已介入调查。  
🔗 https://krebsonsecurity.com/2026/06/popa-botnet-linked-to-publicly-traded-israeli-firm/

3️⃣ **16岁 KVM 漏洞 “Januscape” 影响 Intel/AMD x86 系统，虚拟机可逃逸至宿主机**  
Linux KVM 虚拟化平台被曝存在长达16年的释放后重用漏洞（CVE-2026-？），允许恶意虚拟机破坏宿主机内核的 shadow-page 状态，实现逃逸。该漏洞影响 Intel 和 AMD x86 架构，国内主流云平台已启动应急响应。  
🔗 https://thehackernews.com/2026/07/16-year-old-linux-kvm-flaw-lets-guest.html

## 🔐 API 安全

1️⃣ **SAML 认证再遭突破：“The Fragile Lock” 实现 Ruby/PHP 全绕过**  
PortSwigger 研究员公布针对 SAML 协议的新型绕过技术，利用 Ruby 和 PHP 生态中 XML 解析器的不一致性（属性污染、命名空间混淆等），可完全绕过身份认证。该漏洞影响大量使用 SAML 的单点登录系统，建议厂商紧急审计。  
🔗 https://portswigger.net/research/the-fragile-lock

2️⃣ **PortSwigger 启动 2025 年度十大 Web 攻击技术投票，多项涉及 API 安全**  
年度社区评选拉开帷幕，过去一年里 OAuth 滥用、GraphQL 注入、API 鉴权绕过等攻击技术备受关注。安全团队可提交/投票，最终结果将发布在 PortSwigger 官网，为开发者和防御者提供学习参考。  
🔗 https://portswigger.net/research/top-10-web-hacking-techniques-of-2025-nominations-open

## 📊 行业动向

1️⃣ **梆梆安全发布 Q1 移动应用安全报告：超八成 APP 存隐私违规，境外数据外发风险突出**  
报告显示，2026 年一季度移动应用盗版仿冒、高危漏洞、个人隐私违规问题持续高发，其中涉及境外汇聚数据的 APP 比例较去年同期增长 42%，跨境数据传输合规成为企业出海刚需。  
🔗 https://www.4hou.com/posts/pKwQ

2️⃣ **嘶吼 2026 网络安全产业图谱发布，收录 400+ 安全厂商**  
嘶吼安全产业研究院历经数月调研，基于有效问卷 400 余份，正式发布年度网络安全产业图谱。图谱覆盖数据安全、云安全、API 安全、隐私合规等细分赛道，为政企采购选品提供全景参考。  
🔗 https://www.4hou.com/posts/BpoQ

3️⃣ **全球首次 AI Agent 全自动勒索攻击案例被披露**  
安全研究人员发现名为 JadePuffer 的勒索组织使用大型语言模型（LLM）代理自动完成从初始入侵到加密勒索的全过程，无需人工操作。该案例标志着 AI 驱动的自动化攻击已从概念验证走向实战。  
🔗 https://www.bleepingcomputer.com/news/security/jadepuffer-ransomware-used-ai-agent-to-automate-entire-attack/

## 🛠️ 开源工具

1️⃣ **Gitea Docker 镜像严重漏洞 CVE-2026-20896 已遭探测**  
Sysdig 监测到攻击者在漏洞披露 13 天后即开始扫描利用 Gitea Docker 镜像中的关键漏洞（CVSS 评分 9.9）。Gitea 作为主流自托管 Git 平台，国内大量开发团队受影响，请立即升级到最新稳定版。  
🔗 https://thehackernews.com/2026/07/threat-actors-probe-gitea-docker-flaw.html

2️⃣ **KVM 虚拟化漏洞 “Januscape” 修复补丁已发布，开源社区提醒云厂商及时更新**  
针对影响 Intel/AMD x86 系统的 KVM 内核漏洞，Linux 内核社区已发布补丁。开源云平台（如 OpenStack、KubeVirt）用户需密切关注发行版更新，避免因虚拟化逃逸导致数据泄露。
