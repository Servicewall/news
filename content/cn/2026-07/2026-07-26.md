## 📜 政策合规

1. 📜 **公安部通报37款违规应用，电商类占比超七成**  
   依据《网络安全法》《个人信息保护法》等，公安部检测发现37款移动应用存在违法违规收集使用个人信息问题，其中支付宝、微信小程序为“重灾区”。通报点名《奇峰商城》《聚优商城》等21款未公开收集使用规则的应用，小程序不再是“法外之地”。  
   [查看原文](https://www.4hou.com/posts/PGXA)

2. 🌍 **CISA就GitHub凭据泄露发布复盘：供应商管理成短板**  
   CISA承包商将包括AWS GovCloud密钥在内的数十条内部凭据发布至公开GitHub仓库。事件复盘报告强调密钥轮换、仓库扫描及供应商背景审查的重要性，为国内外政企的DevSecOps实践敲响警钟。  
   [查看原文](https://krebsonsecurity.com/2026/07/lessons-learned-from-cisas-recent-github-leak/)

## 🚨 漏洞威胁

1. 🚨 **梆梆安全Q1报告：超八成APP存隐私违规，境外数据传输风险高**  
   报告基于移动应用监管平台监测数据指出，当前国内移动应用面临盗版仿冒、高危漏洞、个人隐私违规等多重挑战。超过80%的APP存在隐私合规问题，数据境外外发风险需行业高度警惕。  
   [查看原文](https://www.4hou.com/posts/pKwQ)

2. 🚨 **Cl0p 勒索组织利用 PTC Windchill / FlexPLM RCE 漏洞攻击**  
   与 Cl0p 勒索团伙关联的攻击者正在扫描暴露在互联网上的 PTC Windchill 和 FlexPLM 实例，利用未授权远程代码执行漏洞进行初始入侵。国内工业制造企业应紧急排查并修补相关资产。  
   [查看原文](https://thehackernews.com/2026/07/cl0p-affiliates-target-internet-exposed.html)

## 🔐 API 安全

1. 🔐 **Fastjson 1.x 在野 RCE 攻击活跃，官方补丁尚未发布**  
   阿里开源的 Java JSON 库 Fastjson 1.x 版本被曝遭大规模在野利用，攻击者通过构造恶意 JSON 请求可在 Spring Boot 应用上执行任意代码。安全公司建议开启 WAF 规则并升级至2.x分支。  
   [查看原文](https://thehackernews.com/2026/07/fastjson-1x-rce-vulnerability-targeted.html)

2. 🔐 **PortSwigger 披露 SAML 认证绕过新手法**  
   研究人员发现针对 Ruby 和 PHP SAML 实现的新型绕过技术，通过属性污染、命名空间混淆等解析器层不一致性，攻击者可完全绕过身份验证。该漏洞影响大量使用 SAML 的单点登录系统。  
   [查看原文](https://portswigger.net/research/the-fragile-lock)

## 🛠️ 开源工具

1. 🛠️ **GitLab RCE PoC 公开，影响自管理 18.11 版本**  
   安全研究员 depthfirst 发布 GitLab 远程代码执行漏洞的完整利用代码。该漏洞允许已认证用户以 `git` 用户身份执行任意命令，GitLab 已于6月10日修复。自管理实例需立即升级。  
   [查看原文](https://thehackernews.com/2026/07/researcher-publishes-gitlab-rce-poc.html)

2. 🤖 **开源 AI 代理 Hermes 被用于自动攻击泰国财政部**  
   威胁行为者使用开源 Hermes AI agent 在无人值守的“YOLO”模式下，自动完成对泰国财政部网络的后渗透操作。此举标志着 AI 武器化从辅助工具迈向全自动化攻击的新阶段。  
   [查看原文](https://www.bleepingcomputer.com/news/security/hermes-ai-agent-used-to-automate-attack-on-thai-finance-ministry/)
