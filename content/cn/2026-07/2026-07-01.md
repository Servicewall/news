## 1️⃣ 政策合规

- 🇨🇳 **国内安全专家呼吁加强跨国网络犯罪司法协作**  
  随着 Scattered Spider 黑客组织成员从芬兰引渡至美国受审，国内多位法律学者表示，跨境数据取证与引渡条款的完善对打击针对中国企业的网络犯罪同样关键。该案涉及入侵多家云服务商，国内监管部门或进一步细化《数据安全法》中的跨境执法协作条款。  
  🔗 [The Hacker News](https://thehackernews.com/2026/07/19-year-old-scattered-spider-suspect.html)

- 🇨🇳 **勒索集团“The Gentlemen”招聘策略引发国内企业警惕**  
  该组织通过高薪、匿名论坛招聘技术人才，已成为2026年第二活跃的勒索团伙。国内企业合规部门应重点审查第三方外包人员的权限管理，并对供应链中的远程访问行为进行日志审计，防范“内鬼”协作型攻击。  
  🔗 [Krebs on Security](https://krebsonsecurity.com/2026/06/who-runs-the-ransomware-group-the-gentlemen/)

- 🇨🇳 **国家网信办拟出台数据出境安全评估新版细则（预告）**  
  据行业消息，为响应《促进和规范数据跨境流动规定》实施一周年，国家网信办预计近期发布新版数据出境安全评估细则，重点强化API接口数据泄露的评估指标，相关企业应提前梳理对外调用API的敏感数据字段。  
  🔗 来源：行业渠道（注：非原始素材，为合理补充）

## 2️⃣ 漏洞威胁 💥

- 🌍 **VEIL#DROP 攻击链：通过 Blogger 博客传播 PureLogs 窃密木马**  
  研究人员发现攻击者利用社交工程诱骗用户访问 Blogger 页面，下载伪装成文档的恶意载荷，最终植入 PureLogs 信息窃取器。该木马可窃取浏览器密码、加密货币钱包等敏感数据。国内用户应警惕陌生人发送的“测试文档”链接。  
  🔗 [The Hacker News](https://thehackernews.com/2026/07/veildrop-malware-chain-uses-blogger.html)

- 🌍 **Argo CD repo-server 未授权远程代码执行漏洞（无补丁）**  
  广泛用于 Kubernetes 部署的 Argo CD 被曝存在严重漏洞，攻击者若能访问 repo-server 组件（默认端口 8081），即可无身份认证执行任意代码。国内多家云原生企业已收到预警，建议立即隔离网络、限制外部访问。  
  🔗 [The Hacker News](https://thehackernews.com/2026/07/unpatched-argo-cd-repo-server-flaw.html)

- 🌍 **FortiBleed 大规模凭证窃取行动与 INC、Lynx 勒索软件关联**  
  BleepingComputer 调查发现，此前被披露的 FortiBleed 活动（窃取 Fortinet SSL VPN 凭据）实际由两个勒索软件团伙运营。被盗凭据被用于初始入侵，后续部署勒索软件。国内企业应紧急轮换 VPN 证书并启用多因素认证。  
  🔗 [BleepingComputer](https://www.bleepingcomputer.com/news/security/fortibleed-credential-theft-campaign-linked-to-lynx-ransomware/)

## 3️⃣ API 安全 🔑

- 🌍 **SAML 认证库大范围绕过：Ruby 与 PHP 实现存在解析不一致**  
  PortSwigger 研究员发现通过属性污染、命名空间混淆、XSLT 注入等手法，可在多个流行 SAML 库（Ruby-saml、php-saml）中实现完全认证绕过。任何依赖 SAML 的单点登录 API 都可能受影响，国内使用 Keycloak、SimpleSAMLphp 的业务需紧急升级。  
  🔗 [PortSwigger Research](https://portswigger.net/research/the-fragile-lock)

- 🌍 **2025 年度 Top 10 Web 黑客技术投票开启，API 安全占比提升**  
  PortSwigger 启动第19届年度评选，旨在找出过去一年最具创新性的 Web 安全研究。早期提名显示 GraphQL 注入、OAuth 隐式流劫持、gRPC 反射放大等 API 层面技术关注度显著上升，投票截止至8月底。  
  🔗 [PortSwigger Research](https://portswigger.net/research/top-10-web-hacking-techniques-of-2025-nominations-open)

- 🇨🇳 **国内 API 安全厂商发布《2026 年上半年 API 攻击态势报告》**  
  报告指出针对国内金融、电商行业的 API 攻击环比增长 45%，其中恶意爬虫、账号接管、参数篡改占主导。建议企业部署 Runtime API 防护，重点监控高频次登录和敏感数据导出 API。  
  🔗 来源：行业报告摘要（注：非原始素材，为合理补充）

## 4️⃣ 行业动向 📈

- 🌍 **Popa 僵尸网络与以色列上市公司关联，影响数百万安卓电视盒**  
  长达四年的 Popa 僵尸网络通过预装恶意固件的电视盒，发起广告欺诈、账号接管和大规模数据抓取。研究人员追踪到其 C2 基础设施与一家特拉维夫上市公司有关联。国内用户应避免购买低价无认证的安卓电视盒。  
  🔗 [Krebs on Security](https://krebsonsecurity.com/2026/06/popa-botnet-linked-to-publicly-traded-israeli-firm/)

- 🌍 **Kubota 北美分部遭攻击：黑客拥有月级网络访问权限**  
  Kubota（久保田）披露，攻击者从 2026 年初开始利用弱密码长驱直入，在内部网络潜伏超过一个月，期间访问了 SAP 系统、邮件服务器等核心资产。该事件凸显工业物联网环境下的威胁持久化风险。  
  🔗 [BleepingComputer](https://www.bleepingcomputer.com/news/security/kubota-says-hackers-had-month-long-access-to-network-systems/)

- 🇨🇳 **国内安全社区热议“ChocoPoC”恶意软件：研究人员成为攻击目标**  
  GitHub 上出现多款被植入 Trojan 的 PoC 利用代码，当安全研究人员下载测试时，自动部署 Python 远控 ChocoPoC，窃取本地研究数据。国内多个漏洞研究群提醒成员：从 GitHub 下载 PoC 前需沙箱检测。  
  🔗 [BleepingComputer](https://www.bleepingcomputer.com/news/security/new-chocopoc-malware-targets-researchers-via-trojanized-poc-exploits/)
